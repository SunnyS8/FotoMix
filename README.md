# 🎉 FotoMix — Праздничный фотоколлаж

Конструктор красивых поздравительных коллажей с днём рождения.
Создавайте открытки из фотографий, стикеров и праздничного оформления —
и выгружайте результат в сверхчётком качестве для печати или мессенджеров.

</div>

---

## ✨ Возможности

- **6 готовых макетов:** «Герой-мозаика», скрапбук-полароиды, обложка журнала,
  золотая праздничная сетка, комикс-поп-арт и гирлянда-полароиды.
- **8 фоновых стилей:** тёмное золото, конфетти, синие искры, тёплое солнце,
  неон-вечеринка, уютное дерево, закатный градиент и белый минимализм.
- **Загрузка и редактирование фото:** зум, поворот, смещение, подписи и
  7 фильтров (яркий, тёплый, винтаж, ч/б, праздничный, мягкий).
- **Стикеры и поздравления:** эмодзи, бейджи, перетаскивание и вращение прямо
  на холсте; готовые пожелания одним кликом.
- **Настраиваемый текст:** шрифты, эффекты заголовка (золото, неон, 3D, свечение),
  размеры и плашка-бейдж.

## 📤 Многоуровневая система экспорта

Внедрён надёжный движок рендеринга, который **гарантированно** формирует
итоговую картинку без сбоев из-за CSS-фильтров, веб-шрифтов или
кросс-доменных изображений. Экспорт работает по трём уровням отказоустойчивости:

1. **Современный `html-to-image`** — точная отрисовка DOM, веб-шрифтов и
   современных CSS-эффектов (Pixel Ratio ×2 для максимальной чёткости).
2. **Оптимизированный `html2canvas`** — резервный движок с санитарным клоном
   узла, `useCORS`/`allowTaint` и масштабом ×2.
3. **Резервный автономный Canvas 2D Ultra-HD движок** (`renderCollageDirectCanvas`) —
   полностью независимый рендер прямо в `<canvas>`, который не зависит ни от
   CSS-парсеров, ни от внешних ресурсов. Включается автоматически, если оба
   предыдущих способа не сработали, поэтому экспорт никогда не «падает».

Логика находится в `src/utils/canvasExporter.ts` (`exportCollageImage`),
а интерфейс — в `src/components/ExportModal.tsx`.

## 🔒 Безопасная обработка фото

- Для всех фотокартинок настроены корректные параметры **`crossOrigin="anonymous"`**
  и **`referrerPolicy="no-referrer"`** (`src/components/PhotoCard.tsx`) — это
  снимает CORS-ограничения при попытке экспорта чужих изображений в canvas.
- Отрисовываются как **пользовательские загруженные фотографии** (через
  `URL.createObjectURL`), так и **праздничные заглушки** с иллюстрированными
  градиентами, если фото ещё не добавлено (`PHOTO_PLACEHOLDERS` в
  `src/data/defaultPhotos.ts`).
- При сбое загрузки конкретного фото движок экспорта рисует аккуратную
  запасную подложку, не ломая весь коллаж.

## 💾 Скачивание и печать

В модальном окне экспорта (`ExportModal`) доступны три способа получить результат:

- **Скачать PNG** — сверхчёткое качество (**Pixel Ratio ×2**) для печати открыток
  и постеров формата А4.
- **Скачать JPG** — компактный файл для быстрой отправки в **Telegram, WhatsApp и VK**.
- **Копировать в буфер** — мгновенная вставка изображения в любой мессенджер
  через **Ctrl+V** (через `navigator.clipboard.write` + `ClipboardItem`).
- **Распечатать** — открывает изображение в окне печати с оптимизацией под А4/открытку.

## 🚀 Локальный запуск

**Требования:** Node.js 18+.

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:3000`.

Сборка production-версии:

```bash
npm run build      # собирает dist/
npm run preview    # предпросмотр собранной версии
npm run lint       # проверка типов (tsc --noEmit)
```
